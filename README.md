# House-Price-Prediction-ML-Project
A Machine Learning project that predicts house prices using data preprocessing, exploratory data analysis (EDA), feature engineering, and multiple regression models including Random Forest and XGBoost. Built using Python, Pandas, Scikit-learn, Matplotlib, and Jupyter Notebook. 

🏠 House Price Prediction using Machine Learning
📌 Project Overview

This project focuses on predicting house prices using Machine Learning techniques. The project includes complete data preprocessing, exploratory data analysis (EDA), feature engineering, model building, evaluation, and prediction.

The main objective is to build an accurate regression model that can estimate house prices based on various housing features.
